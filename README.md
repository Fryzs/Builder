# Builder — патерни «Будівельник» і «Прототип»

Навчальний проєкт на Windows Forms (.NET), що демонструє патерн **Builder** (а також клонування за патерном **Prototype**) на прикладі збирання моніторів.

## Як працює

- `MonitorDirector` покроково збирає монітор: панель, підставка, порти, звук, підсвічування.
- Три будівельники створюють різні конфігурації:
  - **Ігровий** — 27", 2560×1440, 165 Гц, HDR;
  - **Офісний** — 24", Full HD, HDMI + VGA, динаміки;
  - **Дизайнерський** — 32", 4K, USB-C, ергономічна підставка.
- Кнопка клонування створює глибоку копію останнього монітора й додає її до списку.

## Запуск

Відкрийте `Builder.sln` у Visual Studio і натисніть F5.
